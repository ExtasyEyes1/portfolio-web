# Портфолио-резюме

Одностраничный сайт для представления Павла при поиске стажировки, первой работы и дальнейшего развития в разработке, цифровом контенте и DevOps.

## Структура

- `index.html` — семантическая разметка: главная секция, обо мне, образование, навыки, практика, профиль, контакты и footer.
- `style.css` — CSS-переменные, темная визуальная система и Mobile First-адаптивность.
- `theme-overrides.css` — увеличенная типографика меню и палитра светлой темы.
- `script.js` — интерактивность без фреймворков.

## Реализация

Использованы HTML5, CSS3 и чистый JavaScript. Мобильная версия задается базовыми стилями и расширяется через media queries для планшетов и десктопов. В интерфейсе нет фотографий, выдуманных проектов, коммерческого опыта, сертификатов или контактов, которых нет в исходных данных.

JavaScript реализует мобильное меню, плавную навигацию, активную подсветку раздела, анимацию появления при прокрутке, кнопку возврата наверх, переключение между темной и светлой темами с сохранением в `localStorage` и клиентскую валидацию формы. Форма не подключена к серверу: после проверки выводится заметное браузерное уведомление `alert`.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой локальный статический сервер из корня проекта, например `python -m http.server 8000`, после чего перейдите на `http://localhost:8000`.
